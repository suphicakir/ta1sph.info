## Pardus Nedir?

Pardus, TÜBİTAK tarafından geliştirilen milli Linux dağıtımıdır.
Debian tabanlı olup kararlı ve güvenli bir yapı sunar.

## Node.js Kurulumu

Terminalde şu komutları çalıştır:

<pre><code>curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs</code></pre>

Pardus üzerinde verimli çalışmak için önerilen araçlar:

- **VSCode** → Kod editörü
- **Git** → Versiyon kontrolü
- **npm** → Paket yöneticisi
